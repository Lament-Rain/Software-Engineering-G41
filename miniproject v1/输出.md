# 输出记录

## 本次修改概览

### 1) Admin Dashboard / Workload 相关
- 删除了 `Scheduled Reports` 按钮（由 Analytics 承接类似能力）。
- `Bulk Operations` 改为弹出选项，并拆分为 5 个独立项：
  - `User Enable`
  - `User Disable`
  - `Job reviewed`
  - `Job available`
  - `Job closed`
- `Workload Overview` 顶部工具栏改为与外部页面统一导航结构（Home / User Management / Job Management / System Settings / Approval Center / Analytics / Logout）。
- 保留并可用：`Show overload only` 筛选、`Use AI Comment`、`Push to TA`。

### 2) 注册页体验与校验
- 修复问题：手机号位数不合法时，不再误报 `Username already exists`。
- 现在手机号错误会在手机号字段处给出明确提示：
  - `Phone number must be 11 digits and start with 1`

### 3) 编译故障修复
- 定位并修复 `RegisterController.java` 中异常字符污染问题（日志中表现为大量反引号相关非法字符）。
- 清理后恢复可编译状态。

### 4) TADashboard 顶部卡片点击行为修复
- `Jobs` 卡片：跳转到 `TAJobBoard.fxml`（Job Requirement 页面）。
- `User` 卡片：跳转到 `TAApplicationHistory.fxml`（Application Management 页面）。
- `Tasks` 卡片：保持刷新待办列表逻辑。
- `Workload` 卡片：保持仅展示，不触发跳转。

### 5) Apply 按钮策略调整（TA 端）
- 在岗位详情页中，`Apply` 按钮默认保持可点击且文案固定为 `Apply`。
- 所有不可申请场景改为“点击后弹窗提示并阻止提交”，包括：
  - Profile 未审批通过
  - 截止日期已过
  - 已存在有效申请（非 Withdrawn / Rejected）
  - 超过最大工作量阈值

### 6) Job Board 新增 `MO` 列
- TA/MO 两侧 Job Board 列表均新增 `MO` 表头。
- 显示内容改为“发布该岗位的 MO 账号（username）”。
- 解析策略：优先 `moId`，再回退 `publisherId`，最后回退 `publisherName`。

### 7) Admin Job Management 功能补齐
- `Review Selected`：补全操作流程（未选中提示、输入 review comment、提交状态更新）。
- `Edit Selected`：从“仅可编辑 description”扩展为可编辑完整岗位字段：
  - Title / Department / Type / Work Time / Recruit Number / Deadline / Salary / Location / Skills / Description / Extra Requirements
- 增加基础数据校验（如 Recruit Number 必须为非负整数）。

### 8) Pending Tasks 双击跳转报错修复
- 修复双击 `Profile Under Review` 触发 `Update Profile` 时的 stage 获取失败。
- 为非按钮触发场景增加窗口兜底获取逻辑（从当前 Scene 节点回溯 Stage）。

### 9) AI 配置读取兼容修复
- `AIService` 中 API 配置路径已改为：`data/api_keys.txt`。
- 保存配置时自动创建 `data/` 目录，避免首次写入失败。
- 读取配置支持兼容回退：
  - 优先读取 `data/api_keys.txt`
  - 若为空/不存在，再读取旧路径 `api_keys.txt`
- 解决报错：`API key is not set`（因路径迁移导致读取不到 key）。

### 10) 编译错误快速修复记录
- 修复缺失 import：
  - `JobListController` 补 `UserService`
  - `TADashboardController` 补 `UserRole`
- 修复 `ApplicationService.java` 文件尾部多余 `}` 导致的编译错误：
  - `需要 class、interface、enum 或 record`
