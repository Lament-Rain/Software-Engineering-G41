# Change Log (2026-05-20)

## Completed Updates

### 1) MO AI Ranking: Always show AI score for each TA
- In MO Application Review, AI ranking now always displays a score for every TA row.
- The displayed score is recalculated from current TA profile + target job instead of relying on stale stored values.

### 2) Remove Language Skill from practical usage
- Removed `Language Skills` input from `TAProfileEdit` page.
- Removed `Language Skills` display from `TAProfileView` page.
- Removed language-skill contribution from AI scoring logic so it no longer affects recommendation score.

### 3) TA homepage task behavior for profile completion
- After TA submits profile, the profile task remains visible as **Profile Under Review** while status is `PENDING`.
- The profile-related task is removed only after approval (i.e., when profile is no longer `DRAFT/PENDING`).

### 4) TA keyboard shortcut hints updated
- Removed `Ctrl+F` shortcut hint text from TA Dashboard footer.
- Added explicit timetable hint that **holding Ctrl supports multi-select** for schedule cells.

### 5) AI Job Matching scoring: time conflict as explicit weight
- Added time-conflict weight into application match score calculation:
  - No time conflict: weight = `100%` (1.0)
  - Time conflict: weight = `50%` (0.5)
- Final match score is now: `base score × time-conflict weight`.
- MO review score display uses this updated calculation.
